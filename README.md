# Tab Peek

Hold **⌘** in Chrome and every tab shows the number its ⌘1–⌘9 shortcut jumps to, right on the tab. Let go and everything goes back to normal.

- Tabs 1–8 show `1 · Title` … `8 · Title`. The last tab shows `9`, because ⌘9 always jumps to the last tab. Tabs in between get no number, since no shortcut reaches them.
- **Show number on favicon** (off by default) also puts a number badge on each tab's icon. This helps when tabs are too narrow to show a title. You can pick the badge color.
- A quick ⌘C or ⌘T doesn't make numbers flash. They only appear after ⌘ has been held on its own for a moment. Options offer Fast, Normal and Relaxed delays.
- **⇧⌘9** shows the numbers for 3 seconds, and pressing it again hides them. Chrome handles this shortcut itself, so it works even on pages where holding ⌘ can't be detected. Change it at `chrome://extensions/shortcuts`.
- Click the toolbar icon to open the options.

## Install (unpacked)

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and choose this folder.
3. Tabs that were already open start working right away.

After editing the code, click the reload icon on the extension's card.

## Limitations

These come from Chrome, not from this extension:

- Chrome doesn't let extensions change `chrome://` pages, the New Tab page, the Chrome Web Store, or the built-in PDF viewer, so those tabs never show a number. While you're on one of them, holding ⌘ does nothing; use ⇧⌘9 instead.
- Tabs that Memory Saver has put to sleep show their number once you've opened them again.
- Holding ⌘ only works while the page has focus. If you're typing in the address bar, click the page first.

## Layout

| Path | What it does |
| --- | --- |
| `src/content.js` | Detects a held ⌘, and applies and restores the title and favicon |
| `src/background.js` | Works out labels the same way Chrome's shortcuts do, and tells each tab to show or hide its number |
| `src/badge.js` | Draws the favicon badges and the extension icon |
| `src/settings.js` | Settings, their defaults, and the color and delay choices |
| `options/` | Options page, with a live preview |
| `icons/` | Extension icons, generated by `dev/make-icons.html` |
| `dev/badge-preview.html` | Preview of the badge design |

To view the `dev/` pages, serve the folder over HTTP (for example `python3 -m http.server 8765`) and open them under `/dev/`.
